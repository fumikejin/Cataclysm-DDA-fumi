# CDDA Python 重写项目 - 开发方案和详细步骤

## 项目概述

本项目旨在使用 Python 和 PySide6 完全重写 Cataclysm: Dark Days Ahead (CDDA)，保持与原游戏相同的机制和模块。本项目仅用于学习源代码和 Python 编程，不作商业用途。

### 技术栈

- **编程语言**: Python 3.10+
- **GUI 框架**: PySide6 (Qt6 的 Python 绑定)
- **数据存储**: JSON 文件（与原游戏格式兼容）
- **测试框架**: pytest
- **代码质量**: black (格式化), mypy (类型检查), flake8 (代码检查)

#### 步骤 6: 坐标系统实现

**目标**: 实现 CDDA 的多层坐标系统

**关键概念**:
- **格子 (Tile)**: 最小单位，表示一个游戏方格
- **子地图 (Submap)**: 12x12 格子的区域
- **地图 (Map)**: 多个子地图的集合，通常是 11x11 子地图
- **大地图 (Overmap)**: 180x180 大地图地形单元
- **Z 层级**: 垂直高度层

**坐标转换**:
```python
# coordinates.py
class Coordinates:
    """坐标转换工具"""
    
    SUBMAP_SIZE = 12  # 子地图大小
    
    @staticmethod
    def tile_to_submap(tile_pos: Tripoint) -> Tripoint:
        """格子坐标转子地图坐标"""
        return Tripoint(
            tile_pos.x // Coordinates.SUBMAP_SIZE,
            tile_pos.y // Coordinates.SUBMAP_SIZE,
            tile_pos.z
        )
    
    @staticmethod
    def tile_local(tile_pos: Tripoint) -> Tripoint:
        """获取格子在子地图内的局部坐标"""
        return Tripoint(
            tile_pos.x % Coordinates.SUBMAP_SIZE,
            tile_pos.y % Coordinates.SUBMAP_SIZE,
            tile_pos.z
        )
```

```python
class Submap:
    """子地图 (12x12)"""
    
    SIZE = 12
    
    def __init__(self, x: int, y: int, z: int):
        self.x = x
        self.y = y
        self.z = z
        self.tiles = [[Tile("t_grass") for _ in range(self.SIZE)] 
                      for _ in range(self.SIZE)]
        self.spawns = []      # 怪物生成点
        self.vehicles = []    # 车辆列表
        self.npcs = []        # NPC 列表
    
    def get_tile(self, local_x: int, local_y: int) -> Tile:
        """获取局部坐标的格子"""
        if 0 <= local_x < self.SIZE and 0 <= local_y < self.SIZE:
            return self.tiles[local_y][local_x]
        return None
    
    def set_terrain(self, local_x: int, local_y: int, terrain_id: str):
        """设置地形"""
        tile = self.get_tile(local_x, local_y)
        if tile:
            tile.terrain_id = terrain_id
```

**8.3 地图类 (map.py)**
```python
class Map:
    """游戏地图"""
    
    def __init__(self):
        self.submaps = {}  # 字典存储子地图，键为 (x, y, z)
        self.center = Tripoint(0, 0, 0)
    
    def get_submap(self, x: int, y: int, z: int) -> Submap:
        """获取或创建子地图"""
        key = (x, y, z)
        if key not in self.submaps:
            self.submaps[key] = Submap(x, y, z)
        return self.submaps[key]
    
    def get_tile(self, pos: Tripoint) -> Tile:
        """获取全局坐标的格子"""
        submap_pos = Coordinates.tile_to_submap(pos)
        local_pos = Coordinates.tile_local(pos)
        
        submap = self.get_submap(submap_pos.x, submap_pos.y, submap_pos.z)
        return submap.get_tile(local_pos.x, local_pos.y)
    
    def set_terrain(self, pos: Tripoint, terrain_id: str):
        """设置全局坐标的地形"""
        submap_pos = Coordinates.tile_to_submap(pos)
        local_pos = Coordinates.tile_local(pos)
        
        submap = self.get_submap(submap_pos.x, submap_pos.y, submap_pos.z)
        submap.set_terrain(local_pos.x, local_pos.y, terrain_id)
```

```python
class Inventory:
    """库存系统"""
    
    def __init__(self):
        self.items = []
        self.volume_capacity = 2500  # 毫升
        self.weight_capacity = 13000 # 克
    
    def add_item(self, item: Item) -> bool:
        """添加物品"""
        if self.can_add(item):
            self.items.append(item)
            return True
        return False
    
    def remove_item(self, item: Item):
        """移除物品"""
        self.items.remove(item)
    
    def can_add(self, item: Item) -> bool:
        """检查是否可以添加物品"""
        new_volume = self.get_total_volume() + item.get_type().volume
        new_weight = self.get_total_weight() + item.get_weight()
        
        return (new_volume <= self.volume_capacity and 
                new_weight <= self.weight_capacity)
    
    def get_total_volume(self) -> int:
        """获取总体积"""
        return sum(item.get_type().volume for item in self.items)
    
    def get_total_weight(self) -> int:
        """获取总重量"""
        return sum(item.get_weight() for item in self.items)
```

```python
        # 计算命中率
        hit_chance = self.calculate_hit_chance(attacker, defender)
        
        # 判定是否命中
        if random.random() * 100 < hit_chance:
            # 计算伤害
            damage = self.calculate_damage(attacker, defender)
            
            # 应用伤害
            defender.hp_cur -= damage
            
            # 记录消息
            log_message(f"{attacker.name} 攻击 {defender.name}，造成 {damage} 点伤害")
        else:
            log_message(f"{attacker.name} 的攻击未命中 {defender.name}")
    
    def calculate_hit_chance(self, attacker: Character, defender: Character) -> float:
        """计算命中率"""
        # 基础命中率
        base_chance = 50.0
        
        # 攻击者敏捷加成
        base_chance += attacker.dex * 2
        
        # 防御者闪避
        base_chance -= defender.dex * 1.5
        
        # 武器技能加成
        # ...
        
        return max(0, min(100, base_chance))
```

```python
    """

        p1: 第一个点
        p2: 第二个点
```
